`Nikita-Filonov/ai-review`.

1. `001-agent-loop-core.md` - Agent loop core with PR-Agent AI handler adapter
2. `002-read-only-repo-tools.md` - Read-only local repository tool execution
3. `003-review-agentic-mode.md` - Agentic `/review` integration behind config
4. `004-improve-agentic-mode.md` - Agentic `/improve` integration behind config
5. `005-provider-repo-root-resolution.md` - Provider-aware repository root resolution
6. `006-agentic-docs-and-operations.md` - Documentation, logs, and operational guidance
